# GTA 6 & Take-Two (TTWO)

Página web informativa sobre los avances de **GTA 6** y por qué fluctúa la acción de **Take-Two Interactive (TTWO)** a causa de las noticias.

## Contenido

- `index.html` — página principal (HTML + CSS autocontenido, sin dependencias externas).

## Ver en local

Abre `index.html` en tu navegador, o sirve la carpeta con:

```bash
python3 -m http.server 8000
```

Y visita http://localhost:8000

## Publicar con GitHub Pages

1. Ve a **Settings → Pages** del repositorio.
2. En *Source* elige la rama **main** y la carpeta **/ (root)**.
3. Guarda y en unos minutos estará en `https://<usuario>.github.io/gta6-take-two/`.
